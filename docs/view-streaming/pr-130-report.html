1. Что и зачем

WebGPU-путь панели не имел автоматического теста (headless Chromium не даёт WebGPU-адаптер на этой машине, L30). PR 7 добавляет committed headed-browser тест: Playwright запускает headed Edge (--enable-unsafe-webgpu), грузит stand.html, проверяет adapter и non-black pixels скриншота canvas во всех modes (3D/slice/MPR) и techniques (tissue/isosurface/MIP/transfer_function). Скриншот (pngjs), а не drawImage — WebGPU canvas не preserveDrawingBuffer.

Тест скипается gracefully (exit 0 SKIPPED) без браузера/адаптера/playwright — CI не падает (паттерн test_panel.py). Rendering rule: тест проверяет существующий рендерер (stand.html + ferrum_wasm.js), image-formation не добавляет.

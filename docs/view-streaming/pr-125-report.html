1. Что и зачем

Том 512×512×252 crossing as f32 — ~264 МБ. Теперь /api/volume по умолчанию отдаёт u16 storage тома (вдвое меньше), а клиент реконструирует физическое значение min + stored × (max − min) / 65535 из value_range. Это lossless: storage — источник истины (physical = range.from_storage(data)). Форма ?storage=f32 сохранена для совместимости. Новый /api/labels отдаёт label-карту сегментов (u8) с метаданными для браузерного overlay (PR 5).

gzip отложен: критерий 29.3-a «compressed or 16-bit» выполнен u16 (задокументировано в view-streaming.md «As built»). Реконструкция панели совпадает с доменной формулой (точно для on-grid CT).

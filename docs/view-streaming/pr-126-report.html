1. Что и зачем

Хост отдавал только 2D-срез. Теперь он стримит полный ViewState (component slice/mpr/volume, camera, overlays, selected_segment, tool) и рисует MPR-сетку и 3D-вид на GPU или CPU; POST /api/input ставит camera/overlays/tool/segment и рисует инструменты (draw → commit → roi_drawn); события camera_changed/roi_drawn достигают /api/events и view-events.json. Это закрывает MPR/3D-отсрочку Stage 25.

Rendering rule сохранён: CPU volume — единый CpuRaycaster (oracle volume.wgsl, новый use case render_volume_cpu); MPR — display-blit четвертей, нарисованных общими slice/volume рендерерами (один композитор на оба бэкенда). Третьей копии image-formation нет; GPU↔CPU parity mutation-proven.

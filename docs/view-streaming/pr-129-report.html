1. Что и зачем

Панель получает TF-редактор (29.2-b) и измерения (29.2-c). TF-редактор — canvas с draggable points (гистограмма, insert/remove/color), влияет на 3D transfer_function рендер. Измерения — tool selector (distance/rect/angle/area) + drag-to-draw; хост считает (tool machine PR 2), панель отображает значения через новый GET /api/annotations.

Rendering rule: TF рисует существующий volume.wgsl (биндинги → bake → set_transfer_function); цветовая полоска — градиент браузера, не копия sampling. Измерения — host-side fallback, который дизайн §5 прямо называет (панель без ferrum-app-зависимости). Отступление зафиксировано в view-streaming.md «As built (PR 6)».

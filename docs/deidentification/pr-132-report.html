1. Что и зачем

FERRUM получает стандартную де-идентификацию DICOM: PS3.15 Annex E Basic Application Level Confidentiality Profile. Таблица E.1-1 — данные, не код: 653 атрибута + 4 group-range строки, транскрибированы из официального стандарта (PS3.15 2026d, chapter_E.html), сверены с dicom_dictionary_std. Движок применяет действия стандарта (D/Z/X/U/C/K + compound-коды), рекурсивно в SQ, удаляет private/curve/overlay groups, записывает PatientIdentityRemoved=YES + профиль/опции (CID 7050). 6 опций; default — консервативный Basic Profile.

Privacy-critical: идентификаторы удаляются (mutation-proven — отключение PatientName dummy / odd-group removal / descriptor cleaning / удаление строки таблицы каждое краснит тест). Pixel data kept (Clean Pixel Data — PR 2). UID reuse export::uid_from (один derivation).

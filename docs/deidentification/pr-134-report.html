Де-идентификация становится usable: export bundle --deidentify basic [--deid-option …] де-идентифицирует DICOM SEG/SR под PS3.15 Basic Profile. Вариант A (ADR 0018: agent не линкует app; Exporter port planned, сегодня прямой вызов — существующий паттерн): оркестрация в ferrum-io рядом с export use case (DicomExportOptions.deid), agent/CLI thin. Профиль — единственный privacy gate для DICOM объектов: объекты строятся с исходными identifiers/dates/UIDs (copy flags overridden), затем де-идентифицируются перед записью (write_object → deidentify_file); File Meta Information заменяется консистентно (E.1.1 item 7).

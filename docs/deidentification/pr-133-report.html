1. Что и зачем

Clean Pixel Data маскирует burned-in текст в пикселях и рендерах. Region masking (31.3-a): конфигурируемые прямоугольники заменяются solid fill, остальной image unchanged; BurnedInAnnotation=YES без региона → whole image (консервативно, локация текста неизвестна), flag→NO; encapsulated/unsupported layouts refused (не silently passed). Masked renders (31.3-c): view slice --masked + host ?masked=1. OCR bridge (31.3-b): опциональный ferrum-engine/1 kind (no OCR в Rust, no weights); без бриджа — skip + report.

Rendering rule: masking — pixel transform, не image formation. Volume::masked_copy в domain (app не зависит от io — слоистость); ferrum-render/.wgsl/cpu не менялись. GPU/CPU masked parity проверена.

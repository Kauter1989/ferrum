1. Что сделано

Агент управляет тем, что видит человек, не сидя в render-loop: открывает лёгочное окно, переходит на срез 142, показывает сегмент 3 — а человек перехватывает управление в любой момент. Контракт ferrum-view/1 расширен полным ViewState и JSON-формой событий; состояние стало артефактом workspace, который пишет агент и применяют живые клиенты.

Ключевое решение (ADR 0018): ferrum-agent не линкует ferrum-app/ferrum-view, поэтому состояние — данные в workspace (view.json + view-events.json, слой ferrum-io), а не живой объект. Тип ViewState в домене, apply-use case в приложении, команды читают/пишут артефакт через io.

2. Архитектура и слоистость

ferrum-agent (view set/state/events) ── пишет/читает ──▶ ferrum-io артефакт (view.json, view-events.json)
                                                              │  changes::publish / WorkspaceWatcher
                                                              ▼
хост (ferrum-view / embedder) ── apply via ─▶ ferrum-app::Viewer::apply_view_state
ferrum-ui widget ── рендерит Viewer + to_view_event ─▶ доменный ViewEvent (хост persist'ит)
  • Домен (ferrum-domain): чистые типы ViewState/ViewEvent/ViewComponent/ViewTool/Overlays/ViewProbe/RoiItem с wire-именами; без serde/IO.
  • IO: единственное место, где типы становятся JSON (state_to_json/state_from_json, event_to_json/event_from_json); атомарная запись артефакта; уведомление ViewStateChanged через существующий механизм.
  • App: Viewer::apply_view_state (возвращает события, клампит срез, ничего не блокирует) и view_state (read-back); аксессор выбранного сегмента.
  • UI: to_view_event маппит события кадра в контрактную форму; widget не зависит от io — артефакт смотрит хост.
  • View-хост: refresh применяет 2D-подмножество, репортит unhonoured (component/camera/selected/tool — Stage 29), persist'ит кольцо событий.
  • Agent: view set/state/events, схемы, CLI = MCP; ни одна команда не создаёт decision.

Rendering rule не затронут: image-formation (volume.wgsl/raycast.rs) не менялся — только состояние. gpu_parity.rs зелёный.

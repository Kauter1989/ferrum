2. Анализ и честные оговорки

  • Метрика успеха достигнута: 20/20 вызовов с резидентным holder, без CUDA OOM и без ожиданий; fit-check 2816 + 4352 = 7168 ≤ 10094.
  • Assumed-модель: своей модели харнесса на машине нет; holder — репрезентативный 3B Q4 (записано в прогоне). Перезапуск с LLAMA_CMD; §5.3 даёт правило для 7B (nnInteractive уже не помещается — unload_idle моста или меньший контекст).
  • Один транзиентный сбой фазы A: liver-refinement превысил HTTP-таймаут агента (62.8 s, engine_unavailable); тот же вызов успешен в фазе B. Сессия, оставленная таймаутом, завышает card-delta следующего вызова — пики рецепта взяты из чистой фазы B.
  • WSL: per-process VRAM — [N/A], поэтому footprints измеряются дельтой полной памяти карты (L46). Первый holder оказался на CPU: CUDA-runtime llama.cpp — отдельный asset релиза, без него libggml-cuda.so молча не грузится (L47); поймано по 0 MiB дельты, исправлено; guard — ldd.
  • Скрипт прогонов — throw-away (правило field-test skill: приложен в сессии, не коммитится). Баг glob'а счётчика отказов (L48, «20/20» был вакуумным) исправлен в сессионной копии; результаты фаз также прочитаны глазами по step-логу.
  • Рендеры проверены глазами (L1): замкнутые контуры со всех четырёх сторон, печень справа пациента, селезёнка слева (LPS), полупрозрачная заливка корректна.

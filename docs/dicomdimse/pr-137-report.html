1. Что и зачем

Classic PACS (без DICOMweb) достижим через DIMSE: DicomDimseRepository (impl VolumeRepository) на dicom-ul 0.10 — C-ECHO (verify), C-FIND (query), C-MOVE (retrieve через C-STORE SCP → assemble_with LPS). URL dicom://host[:port]/CALLED-AE?filters; namespace {SeriesUID}#d:{host}. Отдельный repository (sync binary транспорт vs async HTTP DICOMweb), добавлен в CompositeRepository — viewer/CLI открывают classic PACS без app-layer изменений.

Send-off boundary (ADR 0021 §5): C-MOVE/C-STORE SCP — host-only (load); C-ECHO/C-FIND — read-only (echo/scan). Agent-команды НЕ добавлены (PR 3). C-STORE SCP по умолчанию in-memory (privacy); opt-in with_receive_dir пишет Part 10 в workspace receive area. dicom-ul sync TCP без TLS → не тянет aws-lc-rs (lock: только dicom-ul + dicom-encoding/transfer-syntax-registry).
